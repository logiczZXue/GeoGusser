传感器定位流水线

工程化能力
可落地的系统设计
不仅是算法原型，更是完整的嵌入式工程系统 — 从固件到上层应用的全栈实现。
01

全链路闭环

嵌入式固件 (C) → ROS 驱动 (Python) → SLAM 算法 (C++) → 上位机可视化，每一层都可独立调试和替换，链路完整可运行。

02

多传感器紧耦合

GPS 提供绝对位置锚点，BME280 提供海拔约束，VIO 提供 200Hz 高频位姿，三者融合弥补各自缺陷：GPS 遮挡恢复、VIO 累积漂移纠正。

03

路径先验知识库

预装载目标区域 GPX 轨迹库 (来自 OpenStreetMap/实地采集)，匹配引擎实时计算当前轨迹与库中路径的相似度，空间+时间双维度对齐。

04

嵌入式就绪

BME280 固件已适配 STM32F103；VINS-Fusion 支持 ARM 交叉编译；ROS 节点可部署于树莓派/DK-2500 Linux 环境。

05

模块化可扩展

GPS/BME280/VIO/匹配引擎各自独立 ROS node，通过 topic 松耦合通信。任一传感器失效不影响其他模块，系统可降级运行。

06

仿真与实采双模式

支持离线传感器数据回放 (demo_sensor_player) 与在线实时采集双模式。开发调试无需每次实地测试，大幅降低迭代成本。
